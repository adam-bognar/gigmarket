Tips for great briefs

The more specific your questions, the faster you can start — and the fewer back-and-forth messages you'll need.

  • ✓ Ask one thing per question to keep it easy for buyers.
  • ✓ Use file upload prompts for logos, brand assets, or reference images.
  • ✓ Multiple-choice options reduce ambiguity and speed up decisions.
  • ✓ Mark only truly essential questions as required — optional ones encourage richer briefs.
